# Execution runbook

## Phase 1 — zero-cost structural gates

1. Verify parent head `831184e1ceb519803591eda441de2672dc8a9939`, PR #53, and issue #54.
2. Run the static verifier.
3. Prove and compile the weighted occupancy criterion.
4. Execute the exact Bernoulli and hypergeometric cover identities.
5. Complete the degree/coefficient ledger for all registered detector families.

**Decision:** if every finite positive kernel has fatal degree or coefficient cost, retain only the connected and rowwise bilinear lanes.

## Phase 2 — exact finite panels and falsification

1. Generate exact increasing-primorial panels at the largest certified feasible values.
2. Compute row counts, occupancy polynomials, factorial cumulants, column overlaps, and admissible detector profiles.
3. Generate matched adversarial incidence matrices.
4. Test whether connected quantities or the proposed rowwise dual distinguish the true panels from the controls.

**Decision:**

- open O4/O5 if connected norms compress materially and a convergence criterion is plausible;
- open O7 if the exact von Mangoldt decomposition exposes a lower-complexity rowwise bilinear target;
- close the method if neither survives falsification.

## Phase 3A — connected-cumulant route

1. Derive connected arithmetic coefficients symbolically.
2. Remove disconnected primorial local factors before estimates.
3. Prove or disprove a zero-free/cluster criterion at `q_X`.
4. Run bounded cluster-size computations only after the norm ledger predicts convergence.
5. Attempt `INT-CCB => INT-AOD` formalization and analytic proof.

## Phase 3B — rowwise parity-breaking route

1. Freeze one von Mangoldt identity.
2. Derive every Type I, Type II, switched, and remainder range.
3. Compute the exact saving required in each piece.
4. Search the literature only against these exact hypotheses.
5. Attempt the smallest sufficient rowwise bilinear theorem.

## Phase 4 — conditional benchmark

State the weakest `RUHL` hypothesis found to imply the target, with tuple size, shift range, centre uniformity, and aggregate error explicit. Mark every result conditional.

## Phase 5 — closeout

1. Update claim, method, exponent, and gate ledgers.
2. Run exact regressions.
3. Build the complete Lean package.
4. Run inherited mainline verifiers.
5. Inspect provider jobs; cancel only orphaned programme jobs.
6. Freeze exactly one successor theorem if the target remains open.

## Compute discipline

No GPU is expected for this programme. CPU jobs must use the smallest adequate flavor. Every remote job has a timeout and a sentinel. A failed or stale job is inspected and cancelled before replacement. Unrelated Voynich or other research jobs are never cancelled.
