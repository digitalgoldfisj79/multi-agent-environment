# O1 — detector admissibility

Let

\[
I_{jm}=1_{\mathbb P}(m)1_{\mathbb P}(P_j+m)
\]

for candidate offsets `ell_j<m<=H`. For a nonnegative weight profile `a=(a_m)`, define

\[
D_j(a)=\exp\!\left(-\sum_m a_m I_{jm}\right),
\qquad
\mathcal O_X(a)=\sum_{j<N}D_j(a).
\]

If row `j` fails, every `I_jm=0`, hence `D_j(a)=1`. Therefore

\[
\mathcal O_X(a)<1
\]

is sufficient for no failures for every nonnegative weight profile.

## Why unrestricted optimization is circular

If the profile may be chosen after the incidence matrix is known, one can allocate weight directly to observed successful columns. Such an optimization already presupposes the information the theorem is meant to prove. It is not an analytic reduction.

## Admissible profiles

A profile must be generated by a preregistered rule

\[
a_m=F_X(m;\mathcal R_X),
\]

where `R_X` contains only registered arithmetic features available before testing whether `P_j+m` is prime. Permitted inputs include:

- `X`, `H`, and the offset `m`;
- the fact that `m` is a candidate prime;
- residues of `m` and `P_j` modulo registered auxiliary moduli;
- local singular-series proxies computed without output-prime tests.

Forbidden inputs include:

- the values of `I_jm`;
- the set of zero or low-count rows;
- post-hoc optimization against the observed incidence matrix.

## Comparison budget

The uniform detector has `a_m=tau_X` and total weight `tau_X M_X`. Every nonuniform profile must obey a registered budget, initially

\[
\sum_m a_m\le\tau_XM_X.
\]

Alternative entropy or `l2` budgets may be tested only with an explicit comparison theorem.

## Formal target

Add a Lean module proving:

1. `D_j(a)>=0` for nonnegative weights;
2. a failed row has `D_j(a)=1`;
3. `sum_j D_j(a)<1` excludes all failures;
4. the uniform profile specializes to the existing exponential detector.

The admissibility of a concrete arithmetic profile remains an external protocol condition and must be checked by the verifier.
