# Random-order flagship audit package

This directory records the first full adversarial reconstruction of the combined integer sequel.

## Current gate

**Provisional pass to external review.** The theorem and all finite structural checks pass. The manuscript is not labelled submission-ready because an independent human novelty and proof assessment remains outstanding.

## Core result

For a uniformly random ordering of the primes in `[X,2X)`, form the nested prime-prefix products and all unordered pair sums. For the reciprocal Fourier frame with prime moduli of size `X^2`, the reconstructed manuscript proves an expected energy bound

`E_sigma E_a <= C M (log X)^9`

uniformly in the natural harmonic range, together with the weighted aggregate and Frobenius-energy bounds.

The theorem is unconditional with respect to prime-distribution conjectures, under its explicit smoothing-frame admissibility hypothesis. It does not cover the increasing primorial order and does not prove Fortune's conjecture.
