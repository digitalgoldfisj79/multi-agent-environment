# Programme protocol

## Frozen source chain

The programme inherits only the proved implications and corrected frontier statements from:

- `INT-AOD`: adaptive exponential occupancy detector and even-Bonferroni conditional benchmark;
- `INT-SOCG`: deterministic terminal-prime stratification, factorial-to-ordinary cumulant transform, local pair scale and prime-modulus walk estimate;
- `INT-SCME`: selected-centre mean subproblem and its review-corrected successor map.

The target chain is

\[
\mathrm{RUHL\!-\!FM}\Longrightarrow\mathrm{INT\!-\!AOD}
\Longrightarrow\text{eventual Fortune},
\]

and remains conditional at the first arrow.

## Gate R0 — source freeze and claim hygiene

Freeze the branch heads, notation, stratum partition, candidate offset universes, detector parameters and the corrected coequal frontier map.

**Kill rule:** reject any source statement that describes `INT-SCME` or exact phase control as the unique remaining obstruction.

## Gate R1 — exact finite Bonferroni theorem

For each deterministic stratum `b`, define

\[
M_{b,k}=\frac1{n_b}\sum_{j\in B_b}(Z_j)_k,
\qquad
G_b(s)=\frac1{n_b}\sum_{j\in B_b}s^{Z_j}.
\]

For even `K_b`, prove the exact upper bound

\[
G_b(1-q_b)
\le
\sum_{k=0}^{K_b}\frac{(-q_b)^k}{k!}M_{b,k}.
\]

No infinite series, zero-free region or cumulant convergence assumption may enter this gate.

## Gate R2 — weakest sufficient factorial-moment hypothesis

Let deterministic model means satisfy

\[
L_b\le\lambda_j\le U_b
\]

and write

\[
E_{b,k}=M_{b,k}-\frac1{n_b}\sum_{j\in B_b}\lambda_j^k.
\]

Define the signed error combination

\[
\mathcal E_b(q,K)
=
\sum_{k=0}^{K}\frac{(-q)^k}{k!}E_{b,k}
\]

and the absolute envelope

\[
\mathcal A_b(q,K)
=
\sum_{k=0}^{K}\frac{q^k}{k!}|E_{b,k}|.
\]

Prove the exact detector-margin criterion

\[
e^{-q_bL_b}
+
\frac{(q_bU_b)^{K_b+1}}{(K_b+1)!}
+
\mathcal E_b(q_b,K_b)
<\frac1{n_bB}.
\]

The absolute condition is the corollary obtained by replacing `mathcal E_b` with `mathcal A_b`.

**Honesty rule:** the signed condition is algebraically minimal but is not promoted as an arithmetic reduction unless a non-circular prime-tuple theorem implies it.

## Gate R3 — parameter and coefficient ledger

Set

\[
M_b^*=n_bB,
\qquad
q_b=(1+3\varepsilon)\frac{\log M_b^*}{L_b},
\qquad
K_b=\lceil\beta\log M_b^*\rceil_{\mathrm{even}}.
\]

For `rho_b=U_b/L_b`, prove

\[
\frac{(q_bU_b)^{K_b+1}}{(K_b+1)!}
\le
(M_b^*)^{-\beta\log(\beta/(e(1+3\varepsilon)\rho_b))}.
\]

Record the exact admissibility inequality

\[
\beta\log\!\frac{\beta}{e(1+3\varepsilon)\rho_b}
\ge1+2\varepsilon.
\]

Verify the registered example and find the smallest convenient integer `beta` supported by the inequality.

## Gate R4 — arithmetic tuple interface

Expand every factorial moment over ordered distinct offset tuples. Split `E_{b,k}` exactly into:

1. a selected-centre prime-tuple residual;
2. a singular-series/model-collapse residual;
3. any registered boundary or prime-power correction.

No literature theorem may be credited with controlling the prime-tuple residual unless it applies uniformly to the actual sparse primorial centres and the growing order `k<=K_b`.

## Gate R5 — cumulant and obstruction interface

State precisely how the finite-order `RUHL-FM` lane differs from `INT-SOCG`:

- `RUHL-FM` assumes factorial moments through `Theta(log X)` and closes by finite Bonferroni;
- `INT-SOCG` seeks an all-orders connected bound and closes by an absolutely convergent Laplace expansion.

Record that `RUHL-FM` bypasses, rather than proves, the separate `INT-SCME`, `INT-LCSK` and `INT-PWOC` inputs.

## Gate R6 — falsification and equivalence audit

Construct abstract occupancy laws showing:

- low fixed-order moments cannot exclude a zero row;
- the growing order and one-row-scale aggregate error are essential;
- the signed error criterion is close to the truncated detector itself and therefore must not be advertised as an unconditional simplification.

## Gate R7 — validation

Run:

- symbolic checks of the Bonferroni and Taylor signs;
- deterministic parameter verification;
- static scans for forbidden overclaims;
- inherited clean-room validation if executable code or formal files are added.

## Gate R8 — closeout

Allowed outcomes:

- `CONDITIONAL_THEOREM_CONSOLIDATED`;
- `ARITHMETIC_INTERFACE_SHARPENED`;
- `NO_NEW_UNCONDITIONAL_PROGRESS`;
- `REFUTED_OR_CORRECTED`.

A closeout must state separately:

1. what is proved;
2. what is conditional;
3. which exact arithmetic estimate remains missing;
4. whether the programme changes the unconditional distance to Fortune.
