# C7 execution — arithmetic source decomposition

**Status:** `CLOSED_AT_ACTUAL_PRIME_POST_H_SCALE`

The first-moment theorem `INT-SCME` requires actual output primes near `P_j`, not almost primes. Exact Vaughan, Heath--Brown or divisor decompositions of `Lambda(P_j+m)` introduce divisor or Dirichlet-polynomial variables on scales extending far beyond

\[
H\asymp X^2.
\]

Since

\[
P_j=\exp((1+o(1))X),
\]

an actual-prime source identity reaches lengths `P_j^theta=exp(theta X)` for fixed positive `theta`. For every modulus `d>H`, each row interval contains at most one offset in a specified residue class. Progression averaging in the `m` variable therefore disappears precisely where the output-prime factorization still has most of its range.

The only remaining averaging variable is the stratum index, of length

\[
n_b\asymp X/(\log X)^{5/2}.
\]

The C5 prime-modulus theorem has an unavoidable diagonal energy term

\[
n_b\sum_{q\le Q}q.
\]

When `Q` enters any exponential-in-`X` source range, this diagonal floor is already far above the absolute one-stratum budget. Cauchy--Schwarz cannot recover the required lower bound. Composite moduli add divisor multiplicity rather than removing this floor.

Classical lower-sieve implementations confined to `d<=H` remain below the positive lower-sieve threshold because the first permitted output factor lies above `sqrt(H)`. Weighted switching leaves the same sparse post-level hyperbola and at best an almost-prime conclusion without a new signed bilinear theorem.

Accordingly, the named source identities do not establish `INT-SCME`, `INT-LCSK` or `INT-PWOC` in the registered ranges. This is a method closure, not a universal impossibility theorem.
