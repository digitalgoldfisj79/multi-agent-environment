# C7 — arithmetic source decomposition

Source identities are secondary and may open only against the explicit C6 kernel.

## Admitted tools

- Heath--Brown identities;
- Vaughan identities;
- divisor switching;
- zero/source decompositions;
- Dirichlet-polynomial large-value estimates.

## Required properties

1. preserve the common row variable `j`;
2. preserve the connected recombination order;
3. retain actual-prime detection after all terms are recombined;
4. cross the absolute one-stratum budget, not only a relative or almost-all norm;
5. account for moduli beyond `sqrt(H)` and the one-offset-per-modulus regime.

## Pass condition

A source-to-connected-frame identity and estimates yielding the C6 dependence radius.

## Kill gate

Close any source lane that loses parity, detects only almost primes, or requires ordinary moving-centre averaging.
