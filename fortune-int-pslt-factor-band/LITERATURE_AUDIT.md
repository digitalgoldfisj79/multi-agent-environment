# Literature and technology audit

## Current unconditional generic short intervals

- Guth–Maynard, *New large value estimates for Dirichlet polynomials*, Annals of Mathematics 203 (2026), proves asymptotics for intervals of length `x^(17/30+o(1))`.
- Matomäki–Merikoski–Teräväinen, *Primes in arithmetic progressions and short intervals without L-functions* (arXiv:2401.17570), proves existence in intervals of length `x^(39/40)` by a multiplicatively structured sieve.

For the Fortune centres, the ambient number is `P_j=exp(Theta(X))` while the window is

`H=Theta(X^2)=Theta((log P_j)^2)`.

Thus every generic power-length theorem remains exponentially far from the required window.

## Why almost-all results do not solve the selected-centre problem

The number of primorial centres in a dyadic prime block is only `N asymp X/log X`, while the ambient centre scale is exponential in `X`. An exceptional set negligible among all integers can contain every selected primorial centre. A restriction theorem for the actual path is required.

## Sieve boundary

The candidate-offset variable has length `H`. Even granting an ideal residue-distribution level `D=H`, the first possible least output factor satisfies `r>ell_j>sqrt(H)`. Hence

`log D/log r < 2`.

The lower linear sieve has no positive lower coefficient at or below this parity boundary. Stronger generic distribution within a length-`H` variable cannot change this inequality because `D` cannot exceed the sequence length without additional structure.

## Consequence

The only live analytic object is a signed, selected-centre, post-level factor incidence. Generic zero-density, Bombieri–Vinogradov, beta-sieve, and dense-centre tools may be components only after a new primorial-specific identity supplies cancellation beyond the `s=2` boundary.
