# Claim ledger

## Inherited proved spine

- candidate collapse below the next-prime square threshold;
- exact equivalence between a prime in the short interval and a prime candidate offset;
- proper-prime-power support at a failed centre;
- one-sided lower-tail criterion and generic failure-gap theorem, kernel checked;
- `INT-PSLT` as a sufficient but open theorem.

## Claims executed in this programme

1. `B1-PP-CAP`: an explicit harmonic-sum cap for proper-prime-power von Mangoldt mass in a window shorter than `2 sqrt(P_j)`.
2. `B1-COMPRESSED`: a variable threshold `B_j asymp X log X` is sufficient for the one-failure argument.
3. `B2-NO-NATURAL-PROPAGATION`: the recurrence map sends every admissible offset beyond the next registered window.
4. `B3-LF-PARTITION`: failed candidates admit a unique least-prime-factor partition beginning above `ell_j`.
5. `B4-SIEVE-BOUNDARY`: the first admissible factor already lies beyond `sqrt(H)`, so even an optimistic level `D=H` gives lower-sieve parameter `s<2`.
6. `B5-POSTLEVEL`: all surviving factor work is a signed thin-hyperbola incidence problem beyond the classical lower-sieve level.

## Explicitly open

- `INT-PSLT` and its compressed variable-threshold form;
- Fortune's conjecture;
- any signed post-level factor-incidence theorem;
- any propagation theorem not using the natural recurrence map;
- any prime-number theorem in logarithmic-square intervals.

No open arithmetic statement may be inserted as a Lean axiom.
