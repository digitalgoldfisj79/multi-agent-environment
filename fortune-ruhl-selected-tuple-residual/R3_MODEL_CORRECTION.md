# R3 — model and correction ledger

## Indicator formulation

With

\[
I_{j,m}=1_{\mathbb P}(m)1_{\mathbb P}(P_j+m),
\]

the factorial moments contain no prime-power correction. At first order one may define `lambda_j` to be the exact registered Hardy--Littlewood model sum, so the first-order model-collapse term is zero by definition. The remaining first-order residual is then precisely the actual selected-centre prime-pair error relative to that output-independent model.

R2 shows that the absolute detector theorem requires this residual to be `O(1)` after averaging over the stratum.

## Von Mangoldt conversion

The only frozen source identity acts on `Lambda(P_j+m)`. The inherited elementary prime-power cap is

\[
O\bigl(X(\log X)^2\bigr)
\]

per row in the weighted source. Dividing by the natural prime-pair weight `asymp X log X` gives only an `O(log X)` occupancy correction.

That was negligible for the earlier linear lower-bound theorem, but it is too large for the `O(1)` RUHL first-order allowance. Hence a von Mangoldt implementation would additionally require a new averaged prime-power exclusion or cancellation estimate. The previous trivial cap cannot discharge the RUHL correction budget.
