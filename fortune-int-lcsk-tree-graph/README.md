## Execution outcome

\[
\kappa_{3,p}=-\frac{p-2}{(p-1)^2},
\]

whereas the exact pair edge is `1/(p-1)`. The three spanning trees therefore contribute only

\[
\frac{3}{(p-1)^2}.
\]

Their ratio is `(p-2)/3`, so no fixed absolute edge constant repairs the pointwise pair-tree inequality for all `p`.

An actual candidate-universe witness occurs at

- `X=18`, `H=324`;
- `p=37>2X`;
- offsets `89,163,311>2X`, all prime and all congruent to `15 mod 37`.

The broader absolute hyperedge ledger also loses a uniform logarithmic saving as the order grows: its effective radius is at best

\[

\]

at order `r`, so no fixed `delta>0` survives through `r=Theta(log X)` using this absolute Brun--Titchmarsh aggregation alone.
