# General weight-zero hook collapse on the q-line

**Date:** 2026-07-25  
**Branch:** `gpt56/d1-main-twisted-descent-20260724`  
**Scope:** generic fixed `q`, `q notin {0,2}`, in the function-field `d=1` hook programme.  
**Status:** **PROVED** for every odd prime `p>=5`. This discharges the first decisive lemma of Route B.

## 1. Setup

Let

\[
U=\mathbf P^1_t\setminus\{+1,-1,\infty\}
\]

and let the generic degree-`p` root cover have geometric monodromy `S_p`. Put

\[
W=\operatorname{Std}=\operatorname{Perm}_p-\mathbf 1,
\qquad
V_i=\bigwedge^iW,
\qquad 0\le i\le p-1.
\]

The fixed-`q` local inertia is already proved:

- at `t=+1` and `t=-1`, inertia is generated by a transposition;
- at infinity,
  \[
  I_\infty=C_p\rtimes C_{(p-1)/2},
  \]
  embedded as the translations and square multipliers in
  \[
  \operatorname{AGL}_1(\mathbf F_p).
  \]

Let `F` denote arithmetic Frobenius. The unramified quadratic class of its action at infinity is the discriminant Kummer character

\[
\varepsilon_q=\chi(u_q),
\]

where the exact normalisation of `u_q` is the one fixed by the root-cover discriminant. For the normal form used in the spectra, this line is

\[
\mathcal L_{\varepsilon_q}=\chi(u_q(t^2-1)).
\]

## 2. Boundary description of weight zero

For a finite-monodromy local system `V` on `U`, the boundary triangle

\[
j_!V\longrightarrow j_*V
\longrightarrow\bigoplus_{x\in\{1,-1,\infty\}}i_{x*}V^{I_x}
\]

and purity give a Frobenius-equivariant exact sequence

\[
0\longrightarrow H^0(U_{\bar{\mathbf F}_p},V)
\longrightarrow \bigoplus_x V^{I_x}
\longrightarrow W_0H_c^1(U_{\bar{\mathbf F}_p},V)
\longrightarrow0.
\]

For the hooks `V_i`, the only global invariant occurs for `V_0=1`. Therefore, in the virtual Frobenius category,

\[
\sum_i(-1)^i[W_0H_c^1(U,V_i)]
=
\sum_x\sum_i(-1)^i[V_i^{I_x}]-[\mathbf1].
\]

It remains to evaluate the three local alternating invariant objects.

## 3. The p-cycle detector

For a subgroup `I` normalized by an operator `F_x`, character averaging gives, for every `r>=1`,

\[
\operatorname{Tr}\left(
F_x^r\mid\sum_i(-1)^i(\bigwedge^iW)^I
\right)
=
\frac1{|I|}\sum_{h\in I}\det(1-F_x^rh\mid W).
\]

For a permutation `g in S_p`,

\[
\boxed{
\det(1-g\mid W)=
\begin{cases}
p,&g\text{ is a single }p\text{-cycle},\\
0,&\text{otherwise}.
\end{cases}
}
\]

Indeed, if `g` has more than one cycle, the eigenvalue `1` remains on `W`. If `g` is a `p`-cycle, its eigenvalues on `W` are all nontrivial `p`-th roots of unity and their `1-zeta` product is `p`.

Thus every local alternating invariant trace is an exact count of `p`-cycles in one inertia coset.

## 4. The two finite punctures contribute zero

At either finite puncture, let `tau` be the inertia transposition. Since `p` is odd,

\[
F_x^r\tau F_x^{-r}=\tau^{p^r}=\tau.
\]

Hence every element of the coset `F_x^r<tau>` commutes with the nontrivial transposition `tau`.

A `p`-cycle has centralizer `C_p`, which contains no transposition. Therefore neither element of the coset can be a `p`-cycle, and

\[
\boxed{
\sum_i(-1)^i[(\bigwedge^iW)^{I_{+1}}]=0,
\qquad
\sum_i(-1)^i[(\bigwedge^iW)^{I_{-1}}]=0
}
\]

as semisimple Frobenius virtual modules.

## 5. Infinity contributes one plus the Kummer line

Identify

\[
I_\infty
=
\{x\mapsto ax+b:\ a\in(\mathbf F_p^*)^2,\ b\in\mathbf F_p\}.
\]

Its order is

\[
|I_\infty|=p(p-1)/2.
\]

An affine permutation `x -> ax+b` is a `p`-cycle exactly when

\[
a=1,\qquad b\ne0.
\]

These are the `p-1` nontrivial translations.

The multiplier square class of the coset `F^rI_\infty` is

\[
\varepsilon_q^r.
\]

- If `epsilon_q^r=-1`, every multiplier in the coset is nonsquare, so it contains no `p`-cycle.
- If `epsilon_q^r=+1`, the coset has square multiplier class and contains exactly the `p-1` nontrivial translations.

Consequently,

\[
\operatorname{Tr}\left(
F^r\mid\sum_i(-1)^i(\bigwedge^iW)^{I_\infty}
\right)
=
\begin{cases}
0,&\varepsilon_q^r=-1,\\
\dfrac{p(p-1)}{p(p-1)/2}=2,&\varepsilon_q^r=+1.
\end{cases}
\]

Equivalently,

\[
\boxed{
\operatorname{Tr}\left(
F^r\mid\sum_i(-1)^i(\bigwedge^iW)^{I_\infty}
\right)
=1+\varepsilon_q^r.
}
\]

Since this holds for every `r`, the semisimplified virtual infinity object is

\[
\mathbf1\oplus\mathcal L_{\varepsilon_q}.
\]

## 6. The theorem

The two finite contributions vanish. The infinity contribution is

\[
\mathbf1\oplus\mathcal L_{\varepsilon_q}.
\]

The boundary exact sequence subtracts the unique global invariant line `V_0=1`. Therefore

\[
\boxed{
\sum_{i=0}^{p-1}(-1)^i
[W_0H_c^1(U,\bigwedge^i\operatorname{Std})]^{ss}
=
[\mathcal L_{\varepsilon_q}].
}
\]

Equivalently, for every `r>=1`,

\[
\boxed{
\sum_i(-1)^i
\operatorname{Tr}(F^r\mid W_0H_c^1(U,V_i))
=\varepsilon_q^r.
}
\]

This is exactly the weight-zero collapse observed at `p=5` and `p=7`: all weight-zero Frobenius constituents cancel between the even and odd hooks except the single discriminant Kummer line

\[
\chi(u_q(t^2-1)).
\]

## 7. Consequences

### Proved

1. The exponential raw weight-zero boundary cohomology cancels for every `p`, not only at the calibrated primes.
2. The arithmetic unramified quadratic at infinity is not a bookkeeping hazard to be removed; it is precisely the surviving Kummer class.
3. The remaining fixed-`q` effective defect is entirely weight one, apart from this one rank-one line.
4. Any failure of the full `O(p)` hook collapse must occur in the weight-one parabolic cohomology, not in puncture permutation modules.
