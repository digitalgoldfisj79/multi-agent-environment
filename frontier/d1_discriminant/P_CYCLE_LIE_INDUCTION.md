# Cyclic-induction model of the p-cycle virtual character

**Date:** 2026-07-22  
**Status:** exact representation identity proved; quotient-geometry realization open.

## 1. Setup

Let `G=S_p`, let `C=<tau>` be a subgroup generated by a p-cycle, and let psi be any nontrivial one-dimensional character of C over a characteristic-zero coefficient field containing the p-th roots of unity.

Let

`Lambda_p=sum_(i=0)^(p-1)(-1)^i exterior^i(Perm_p-1)`.

Its character is p on the p-cycle conjugacy class and zero on every other conjugacy class.

## 2. Two induced characters

The induced trivial character

`Ind_C^G(1)`

has:

- value `(p-1)!` at the identity;
- value `p-1` at a p-cycle;
- value zero on every other conjugacy class.

Indeed, an element contributes only when it is conjugate into C. For a fixed p-cycle, the intersection of its conjugacy class with C consists of all `p-1` nonidentity elements of C.

The induced nontrivial character

`Lie_p=Ind_C^G(psi)`

is the classical prime-degree Lie representation. It has:

- value `(p-1)!` at the identity;
- value `-1` at a p-cycle, because `sum_(u in C-{1}) psi(u)=-1`;
- value zero elsewhere.

Therefore their difference has value zero at the identity, p at every p-cycle, and zero elsewhere.

### Theorem PCLI.1

`boxed(Lambda_p=Ind_C^(S_p)(1-psi).)`

Equivalently,

`Lambda_p=Ind_C^(S_p)(1)-Lie_p`.

A second equivalent identity is

`Lambda_p=Reg_(S_p)-p Lie_p`.

## 3. Artin-formalism consequence

Let L/K be an `S_p`-Galois extension realizing the root cover, and put

`M=L^C`.

Artin formalism gives

`L(Lambda_p,K,T)`
` = L(1-psi,L/M,T)`
` = zeta_M(T)/L(psi,L/M,T).`

Thus the p-cycle exterior character is induced from the rank-zero cyclic virtual character

`1-psi`

on the degree-p cyclic extension `L/M`.

This removes the apparent `2^(p-1)` exterior-power complexity at the representation-theory level.

## 4. Relation to wild inertia

At wild infinity, the local p-Sylow subgroup is precisely a p-cycle group C. Restricting Theorem PCLI.1 to C recovers

`Lambda_p|_C=p*1-Reg_C`.

The nontrivial local character psi is an Artin-Schreier character with one ramification jump. Hence the virtual local conductor is controlled by one cyclic character rather than by all hook representations separately.

## 5. Remaining geometric issue

The quotient curve or surface `M=L^C` has very large degree over the original parameter space. Artin induction alone does not prove bounded global cohomology.

The active task is to exploit the special polynomial cover

`x^p+a x^3+c x-t`

and identify `L/M` explicitly enough that the rank-one character psi becomes an Artin-Schreier sheaf on a bounded-complexity quotient or correspondence.

A bounded-complexity realization of

`R Gamma_c(M,1-psi)`

would give the required `p+O(sqrt(p))` irreducible-fibre count.

## 6. Strategic improvement

The wild-boundary programme is now reduced from an exponentially large virtual representation to two concrete questions:

1. describe the cyclic p-extension `L/L^C` geometrically;
2. control the cohomology of the single nontrivial character psi relative to the trivial character on the same quotient.

This is a genuine compression and is not equivalent to the previously closed Cartier/Krylov basis change.
